# Dedavi Travels

Interactive globe of every place I've visited: pins auto-synced from Google My Maps, political map with highlighted countries, stats by country and region.

- **Globe**: a dark globe (or flat map) with a pin for every place. Countries and territories I have visited are coloured.
- **Stats**: places, countries, territories, continents, share of the 195 UN states, Italian regions, US states, top countries, extreme points and the full list of places.
- **About**: what the site is, when the data was last checked, credits.

The site is a plain web page hosted for free on GitHub Pages. It has no server, no database and no accounts.

## How it works (in short)

1. I keep my travels on a **Google My Maps** map, in the layer called **"Visitati"**.
2. Twice a month (on the 1st and the 15th) GitHub runs a small program automatically. It:
   - downloads the "Visitati" layer of the map,
   - finds the English name of each new place (using OpenStreetMap; names are remembered, so each place is looked up only once),
   - works out the country, territory and region of each place using world borders from Natural Earth,
   - saves the result in `data/places.json`, which the website reads.
3. If something goes wrong (for example the map can't be downloaded), **the website keeps showing the last good data**, and the About page shows that the last update failed.

## One-time setup (manual steps)

1. **Create the repository**: on GitHub, create a **public** repository named `Dedavi_Travels` and upload this project.
   Then go to **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
   After a minute the site is online at `https://dedavi97.github.io/Dedavi_Travels/`.
2. **Share the map**: in Google My Maps, click **Share** and set the map to **"Anyone with the link"** (NOT "public on the web").
   Copy the link: it contains `mid=` followed by a long code. Copy only that code (everything after `mid=` up to the next `&`, if any).
3. **Give GitHub the map code**: in the repository go to **Settings → Secrets and variables → Actions → New repository secret**.
   Name: `MYMAPS_ID`. Value: the code from step 2. Save.
   (It is a "secret", so it never appears in the code or on the website.)
4. **Test it**: go to the **Actions** tab, click **Sync** on the left, then **Run workflow**.
   After about a minute it should show a green tick. The About page on the site will show the new "Last check" time.
   If it shows a red cross, open it to read the message (the same message appears on the About page).
5. **Add it to Google Sites**: **Insert → Embed → By URL**, paste the Pages URL from step 1, choose "Whole page", then stretch the box to the **full width** of the page. A height of about **700 px** works well.

## Everyday use

- **Add a place**: just add a pin to the "Visitati" layer in My Maps. It will appear on the site after the next automatic update (1st or 15th of the month).
- **Update now**: Actions tab → **Sync** → **Run workflow**.
- **Fix a wrong English name**: open `data/name_overrides.json` and add a line like `"Original name": "English name"` (the file `data/name_report.md` lists how every name was found).
- **Fix a wrong country** (rare: only for pins right on a border): add the place to `data/location_overrides.json` with the 3-letter country code used by Natural Earth, e.g. `"Narva": "EST"`.

## Try the site on your computer

Double-click **`run.bat`**. It starts a small local web server and opens the site at http://localhost:8000.
Close the black window to stop it. (Opening `index.html` directly doesn't work: browsers block pages from reading local data files.)
This needs Python installed (https://www.python.org/downloads/).

## Project files

| Path | What it is |
|---|---|
| `index.html`, `assets/` | The website (HTML, CSS, JavaScript) |
| `assets/js/version.js` | The app version shown in the footer |
| `data/places.json` | All places, generated by the sync |
| `data/sync_status.json` | When the last sync ran and whether it worked |
| `data/name_cache.json` | English names already found (never looked up again) |
| `data/name_overrides.json` | Manual name fixes |
| `data/location_overrides.json` | Manual country fixes for border pins |
| `data/name_report.md` | How each name was found, plus location notes |
| `data/geo/countries.geojson` | Simplified world borders used by the map |
| `scripts/sync.py` | The sync program |
| `scripts/build_geo.py` | Rebuilds `countries.geojson` (rarely needed) |
| `.github/workflows/sync.yml` | The automatic twice-a-month schedule |
| `run.bat` | Local test server |
