# CLAUDE.md — Dedavi_Travels

Static site (GitHub Pages, repo `dedavi97/Dedavi_Travels`) showing visited places on a MapLibre globe, plus stats and about views. Embedded in Google Sites via "Embed by URL" (iframe).

## Rules
- Code, comments, UI text, docs: **English**. Talk to the owner (Davide, not a developer) in **Italian**, plain language.
- Vanilla HTML/CSS/JS, no framework, no build step. CDN libs pinned to exact versions.
- SemVer in `assets/js/version.js` (`APP_VERSION`). PATCH = fix, MINOR = feature, MAJOR = breaking. Bump only for commits that change executed code; data-only (sync) and doc-only commits: no bump.
- Keep README.md (owner-facing, simple) and this file updated on every relevant change.
- **Never push without Davide's explicit approval.**

## Layout
- `index.html` — single page; hash routes `#/globe`, `#/stats`, `#/about`, hidden `#/trips-editor`; deep links `#/globe?place=<id>`, `#/globe?explore=<ADM0_A3>`, `#/globe?trip=<trip id>`.
- `assets/js/app.js` — global `DT`: data loading (`data/places.json`, `data/sync_status.json`, optional `data/itineraries.json` → `DT.data.trips`, malformed trips dropped by `DT.validTrips`), router (a route without a tab is hidden), `DT.HOME` (Turin), helpers (`DT.flag`, `DT.escape`, `DT.store` = try/catch localStorage get/set/remove, `DT.haversineKm`). Views register on `DT.views.<name>` with `show(el, params)` / optional `hide()`.
- `assets/js/globe.js` — MapLibre 5.24.0 style built in code (no basemap, no glyphs: cluster counts are HTML markers; country names are a DOM tooltip). Visited fill = Natural Earth `ADM0_A3` units in `place.unit`. Faint `subdivisions` line layer (first-level internal boundaries). Lakes (fill) + rivers (line, shown when `rank <= zoom + 2`) from `water.geojson`; land/visited colours vary slightly by country `tone` (NE MAPCOLOR7 % 4) so neighbours differ. maxZoom 9 (simplified borders get blocky beyond). These were added because the plain map looked "uncanny" to Davide. Clustering: radius 26 px, max zoom 5 (Davide wanted groups to split early). Projection toggle uses a CSS crossfade (MapLibre only morphs projections by zoom); choice saved in localStorage `dt.projection`. Globe is fitted to the viewport after load by measuring projected limb points (`fitGlobe`). Auto-rotation stops on first interaction; disabled with prefers-reduced-motion. **Explore mode**: hover = name only; a click on a visited country pins the tooltip with an Explore button (the only way in, plus the deep link), which sets the hash; `show()` then enters or exits, so the World button, Esc, browser Back and the Globe tab all go through the hash. Loads `data/geo/adm1/<unit>.json` on demand, adds `explore-*` layers (fill under lakes, line under borders), hides the explored country's world fill/border (its coarser shape would double the coastline), dims the others and hides the `subdivisions` lines. Camera frames the `parts` bboxes that hold a pin (not Alaska/French Guiana without pins). Layers survive the projection crossfade, which refits. `DT.mapStyle(opts)` exposes the style builder (`{projection, cluster}`) for the trips editor. **Trips mode** (`?trip=`, mutually exclusive with Explore; the World button, Esc, Back, the Globe tab and the card's × all go through the hash): "Trips" button (hidden without trips) → panel (bottom sheet ≤640px) sorted year desc, no year last; camera fits the stops (padding leaves room for the card, max zoom = place zoom), then the legs are drawn one by one (2–4 s, none with reduced motion), then the card. Pins not in the trip dimmed; clusters dimmed with CSS `filter` (MapLibre owns their inline opacity). Pin popup lists "Part of: <trips>".
- `assets/js/trips.js` — always loaded (small): `DT.MODES` (icon, label, CO₂ factor; UK DESNZ 2025 factors, source in the code comment), `DT.tripStats` (haversine per leg, km per mode, distinct stops, countries from the stops' stored `country`, longest leg, farthest from home), no "countries passed through" (removed: straight lines can't tell, Davide found e.g. a fake Switzerland crossing worse than nothing), `DT.tripCardHtml`, `DT.TripRoute` (GeoJSON source `trip-legs`, one line layer per mode: train solid, car dashed, plane dotted lighter without casing, ferry long dash, bus short dash; numbered HTML stop markers, one per distinct place, "1 · 8" for round trips; missing stops muted). Longitudes are unwrapped so legs go the short way. Also registers the `trips-editor` view that lazy-loads `trips-editor.js`.
- `assets/js/trips-editor.js` — hidden editor, loaded only on `#/trips-editor`. Not linked from nav/footer/About (owner docs: README). Reads `data/itineraries.json?t=<now>` with `no-store` (404 = revision 0). Draft in localStorage `dt.tripsDraft` = `{baseRevision, base (trips at that revision), trips, deleted ids, exported?}`; an untouched draft is not stored. Stale draft (live revision > baseRevision) → dialog Merge (default) / Discard; merge is three-way by trip id (draft-only change kept, live-only change taken, both changed → draft wins and is listed; live trips not in the draft come back unless deleted). Trip id = slug + 4 random chars, follows the name until first exported, then frozen. Save: validation (name, ≥2 stops, mode per leg, year 1900–2100), re-fetch live (merge first if it moved), summary dialog, full file with `revision = live + 1`, `showSaveFilePicker` or download fallback + "exactly itineraries.json" warning, then upload steps. After export the draft keeps `exported`; when the live revision reaches it the draft is cleared (or, if edited after export, rebased on the exported file).- `assets/js/stats.js` — all stats computed client-side. UN list = 193 members + VA + PS. Home = Turin. DC is not counted in US states x/50. Trips section only with ≥1 trip: count, km, Earth laps (40,075 km), % of Earth–Moon (384,400 km), coverage, km per mode share bar, records, per year, CO₂ table with footnote (car = whole car, as if alone, as Davide chose; flights with RF), all trips.
- `assets/css/style.css` — dark theme, accent `#f2b544`. Layout fills the iframe with `height:100%` flex (no 100vh). ≤640px: tabs fixed at the bottom.

## Data pipeline (`scripts/sync.py`, Python 3.12 + shapely)
- Normal: KML from `https://www.google.com/maps/d/kml?mid=$MYMAPS_ID&forcekml=1` (`parse_map_id` also accepts a full My Maps link in the secret), only folder `LAYER_NAME = "Visitati"`. Bootstrap: `--from-csv data/source/visitati.csv` (CSV is git-ignored).
- Failure (download, missing layer → lists layers found, 0 points, missing secret): places.json untouched, status `error`, exit 1. `sync_status.json.last_check` is always updated.
- Names: key = `name|lat5|lon5`. Order: `name_overrides.json` (by key or plain original name) → `name_cache.json` → Nominatim search (bounded ±0.5° viewbox, `namedetails` name:en; up to 5 results, the first whose bounding box is within `SEARCH_MAX_KM` = 15 km of the pin wins, else none: "Varsavia" had matched Warsaw-Modlin Airport 35 km away) → reverse zoom 10 → original. ≥1.1 s between requests, UA with repo URL. Network failures are not cached (retried next run). Report: `data/name_report.md` (also lists location notes).
- Geography: Natural Earth 10m admin-0 countries, **Italian point of view** (`ne_10m_admin_0_countries_ita`: Crimea in Ukraine, Northern Cyprus in Cyprus, Somaliland in Somalia; Davide asked for Crimea in Ukraine) + admin-1 (downloaded to `.cache/naturalearth/` by `scripts/naturalearth.py`, cached in Actions). Sovereign via `SOVEREIGNT` (+ `SOVEREIGN_OVERRIDES`: Palestine). Dependency = `ADMIN != SOVEREIGNT`. Subdivisions only for `SUBDIVISIONS` (ITA region field → English names, USA states, GBR geonunit). Points outside polygons snap to the nearest within 25 km. Border pins: NE borders are off by a few hundred metres (Gorizia, Schengen, Vianden, Narva were wrong), so each pin's OSM country code (Nominatim reverse zoom 3, cached forever in `data/country_cache.json`) wins when it disagrees with NE and a matching unit is within 25 km. `data/location_overrides.json` (`"name": "ADM0_A3"`) still forces a unit as a last resort (currently empty).
- Explore areas: every place gets `adm1` / `adm1_name` (NE admin-1 as is, for every country: Italian provinces, French departments, UK councils; `ADM1_GROUPING` merges listed units into one area, currently only the 33 London boroughs into "London", because Davide found them too many to fill; separate from `SUB_GROUPING` and from `subdivision`, used by the stats). Snap ≤ 25 km within the same unit, else `adm1: null` in the report. An area belongs to the admin-0 unit its interior falls in, because the admin-1 file has its own point of view (Crimea under Russia). Names: `ADM1_NAME_FIXES`, then `name_en` unless repeated in the country (21 Latvian units are "Valmiera"), then `name`. `write_area_files` keeps one `data/geo/adm1/<unit>.json` per visited unit (`version` hash of source + settings: unchanged files are not rewritten; unvisited ones are deleted), with `shapely.coverage_simplify` (no gaps between neighbours), size-aware, target ≤ 400 KB. Foreign member `parts` = bboxes for the camera.
- Trips: `relink_trips` runs after `build`, before the report. For every stop of `data/itineraries.json` (if present; invalid file → warning in the report, sync not failed): pin still there → refresh name/original_name/lat/lon/country/country_iso2; pin gone → nearest pin within `TRIP_RELINK_KM` = 2 km, same name first; none → keep stored data, `"missing": true`. Never touches `revision`; rewritten only if changed; report section "Trips". Stop format: `{name, original_name, lat, lon, country, country_iso2, place_id[, missing]}` (country/original_name added to the handoff's schema so stats and re-linking survive pin changes).
- places.json is rewritten only if content changed (then `last_data_change` updates). Place `id` = first 10 hex of sha1(key).
- `scripts/build_geo.py` regenerates `data/geo/countries.geojson` (~1.8 MB, size-aware simplification keeps microstates) and `data/geo/subdivisions.geojson` (~1.2 MB: internal admin-1 boundaries; NE units merged by `SUB_GROUPING` where they are second-level, e.g. Italian provinces → regions, GBR → nations; outlines/coasts removed). Also `data/geo/water.geojson` (~1 MB: NE 10m lakes scalerank ≤ 7, rivers scalerank ≤ 6).
- Workflow `.github/workflows/sync.yml`: cron `0 6 1,15 * *` + manual; commits `data/` as github-actions bot with `data: sync YYYY-MM-DD` (commit step runs even on failure).
